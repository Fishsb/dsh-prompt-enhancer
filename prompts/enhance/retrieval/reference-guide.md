# 参考上下文使用规则（L2 条件注入：仅当本次输入附带参考/会话/检索上下文时适用）

1. 参考上下文仅用于补充理解任务背景与已确认信息，将参考中明确的需求、约束、默认值、已确认决策**吸收进优化后的提示词**，使其更完整、可执行；但禁止逐字复述、引用或回显参考原文。
2. 参考与原文冲突时，以原文为准；参考未明确、无法推断的细节不得臆造。
3. 参考仅用于补充和明确化，不得扩大、缩小或颠倒原文范围。
4. **参考来源分级（用法不同）**：① 优化历史（记忆链）= 上一轮已确认的优化结果，作为**延续优化依据**；② 任务背景（历史会话）= 优化本次草稿是为继续执行任务，会话提供任务背景与已确认约定，用于**理解草稿意图**；③ 项目事实（文档/代码）= 以文档与代码为准，不臆造。
