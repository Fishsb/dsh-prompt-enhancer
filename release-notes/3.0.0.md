# v3.0.0 — 模式体系重构 + 一键发布升级 + 更新链路完善

> 发布日期：2026-08-16 · 版本线重置发布：自 v2.8.3 以来的全部迭代（原 3.1.x 功能 + 最新未发布改进）统一归档为本版本——检索体系全面重构、一键发布升级为「多步网络检索 + 生成提示词规格」、一键更新链路闭环、保存反馈全状况显式化。

## ✨ 模式体系重构（v3.0）

5 种模式全部重定义，检索从「规则 + 全量」升级为「LLM 判定 + 分级窗口」：

| 模式 | 行为 |
|---|---|
| **基础** | 直发优化，不读取任何上下文（不变） |
| **轻量** | 参考最近 1 轮会话——LLM 判定关联性，有关联才注入参考 |
| **标准** | 递进窗口检索（最近 1-2 轮 → 3-5 轮 → 6-10 轮），每窗口 LLM 判定，命中即停；会话轮次覆盖修正（按轮扫描，最深窗口语义恢复正确） |
| **专家** | 会话窗口检索 → **开发意向判定**（非开发意向直接停）→ 工作区 .md 文档分析（含项目地图结构）→ 代码文档参考（按项目地图路径优先）→ 专业词汇优化 + 调整方案 |
| **一键发布** | 见下方「一键发布 v3.0」 |

- 会话参考**仅注入结论信息**（剥离工具调用/思考过程/系统注入块，注入体积降 85-92%），保留防回显护栏；LLM 判定 10s 超时/失败自动降级（不阻断主流程）
- 新增提示词事实源：relevance / intent / doc-analysis / smart / websearch

## 🚀 一键发布 v3.0（publish 多步检索 + 产物形态调整）

- **多步网络检索**：LLM 自动规划 2~3 个差异化检索主题（避开已检索主题）→ 逐主题搜索 → 结果按主题合并注入【网络参考】（≤1600 字符）
- **跨轮检索记忆**：已检索主题 + 要点摘要会话级记忆（≤600 字符），下一轮以【已获取网络参考】回注，只补新缺口、不重复检索；搜索失败的主题不占位可重试
- **产物形态**：九章规格重写为「**完善、有明确边界的生成提示词**」——场景化角色设定（游戏开发专家/软件架构师）、需求范围与硬边界（绝对/必须/不得）、技术约束与架构（写实到方案名：渲染管线/合批/后处理/材质体系）、核心要求逐条附设计意图、交付与限制（禁止 TODO/占位）、逐条验收清单
- 保留：场景自动路由（游戏/软件/通用）、网络信息运用（标注来源、不得虚构）、方案自评判定（【保留】/【调整】闭环）、多轮完整九章扩充、记忆强制开启、不设输出限制（240s 超时）

## ⏱️ 超时体系按真实耗时校准（实测驱动）

- 真实 LLM 实测：长草稿 + 深度思考完整生成 42s > 默认 30s → **链含思考等级（reasoningEffort）时主调用超时自动放宽 ≥120s**
- 判定/规划类小调用剥离思考等级（5 处），消除「思考消耗小预算 → 空流」风险，10s 超时余量充足（实测 2s 级）
- 会话历史/事件检索补 10s 超时保护（超时降级不阻断）
- **优化响应看门狗 + 延迟连通性预检**：首条模型 3s 内无输出 → 中断并逐个探测模型链 → 第一个通畅模型接手生成；全不通秒级报错（对比旧固定 30s 超时）；fallback 完成时按钮显式显示「✓ {模型} 优化，可撤回」

## 🔄 更新链路闭环（一键更新 / 端口重启）

- **职责划分**：「一键更新」仅下载 + 校验新版本到 staging（服务全程在线）；「端口重启」统一承载安装 + 重启 + 健康检查（重启失败自动回滚旧版本）
- **端口重启绕过 host 直连执行器**（独立进程 3081，服务停止不影响）——修复「更新完成后误报执行器不可用」
- **手动检测总是取最新**（清除两层缓存）——修复「刚发布 tag 后检测不到新版本」
- **一键更新不误触发重启**：client 执行前版本守卫 + 执行器目标版本从磁盘解析（修复旧执行器被 require 缓存锁死、忽略 restart:false 的根因）
- **重启进度反馈**：fire-and-forget + 1s 轮询、逐秒倒计时 + 已用秒数、执行器阶段消息（停止服务/等待稳定/第 N 次重启/端口未就绪）、15s 无响应自动终止

## 🎨 设置界面与交互

- **保存反馈全状况显式化**：任何环境（含无 timer 服务）「已保存」均基于真实校验结果（localStorage 读回逐字对比）显示「✓ 已保存 / ✗ 保存失败，请重试」，**不存在无条件「已保存」**
- 设置界面样式与交互对齐官方 Harness：控件字号/圆角/边框/背景对齐 design platform、tab 键盘导航（roving tabindex + 方向键/Home/End）、可访问性补齐（label htmlFor/id、hint aria-describedby、section 标题 + 简介）
- 智能模式更名为**专家模式**（存量配置零迁移）；设置页纵向间距修复；自定义模板每模式独立（含默认预填）
- **细粒度进度反馈**：检索重模式执行期间按钮进度全程动态（「正在搜索 2/3：体素引擎 · 8s」），消除「卡顿」误判

## 🧹 稳定性与治理

- publish 多步检索审查修复（memo 截断方向、失败主题不入记忆、主题硬去重、预算门前置）
- 文档架构与发布边界规则：功能文档与开发治理文档分开存放，发布物仅含功能文档 + 运行代码（13 文件白名单）
- 架构重构（M0-M6）落地：源码模块化、服务化/事件化、RPC 契约化、更新链路平台化、可观测性与安全加固、CI 全覆盖（语法/单测/构建/生成物一致性）
