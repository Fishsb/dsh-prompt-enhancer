# v3.3.1 — 语音设置体验完善 + 本地引擎一键部署

> 语音设置 UI 精细化、语音总开关、本地引擎一键部署（GitHub #4）、llm 注入修复（GitHub #3）。

## ✨ 新增

- **语音总开关**：识别引擎新增「关闭」选项，关闭后隐藏输入框旁的 🎤 按钮与语音配置；默认引擎改为本地（仅新环境生效）
- **本地引擎一键部署**：本地语音引擎运行时（worker + 底层依赖）缺失时，设置页出现「部署本地引擎」按钮，一键安装并启动，无需手动跑部署脚本

## 🎨 界面

- 语音设置各下拉统一为与提示词增强一致的样式（含箭头、超长滚动）
- 窄屏不再重叠；标签精简为两字；恢复「打开文件夹」按钮；「语言」与「打开文件夹」对调位置
- 修复快捷键清除后输入框不立即清空的问题

## 🐛 修复

- **llm 服务未就绪（NO_LLM）**：插件声明 `llm` 为注入依赖，等待服务就绪后再激活，消除启动竞态导致的「LLM 服务不可用」

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.3.1
```

安装后重启 `dsh web` 生效（桌面端重启客户端并按 Ctrl+F5 刷新）。
