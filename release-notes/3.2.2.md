# v3.2.2 — 一键更新链路根因修复

## 变更

### 修复
- **一键更新→端口重启 90s 超时根治（根因链）**：
  - 安装与 host 解耦：staging tgz 安装不再用 `dsh plugin add`（=pnpm add，操作自身运行中的 profile 会卡死 → host 事件循环冻结 ≥90s → DSH 网页无响应 → 端口重启超时）。改为**直接解包 npm pack tgz 覆盖运行环境目录**（System32 tar 解包 + 文件级复制，秒级完成、无网络无锁；插件加载走 cordis include 不依赖 pnpm 依赖树）。
  - **版本检测修复**：本地版本改为**运行时读取运行环境 package.json**（原构建硬编码导致发版后永远检测到旧版/永远提示更新）。
  - **默认目录修正**：update/check 的更新目标目录改为真实运行环境目录（原显示不存在的幽灵目录）。
- 源码与产物一致性修复：ENV_PROBE_KEYS 回灌 src/host/pure.js（此前只改产物，重建丢失）。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.2
```

安装后重启 `dsh web` 生效。
