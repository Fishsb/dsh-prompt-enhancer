# v2.8.1 — 更新模块重启链路修复

> 发布说明摘要，完整变更见 [CHANGELOG.md](../CHANGELOG.md)。

## 修复内容

- **更新模块重启链路走不通**：一键更新执行到重启服务时，执行器会在 `sc stop dsh-web` 时被连带杀死，导致后续 `stop → start → 健康检查 → 自动重试` 无法继续。
- **修复方式**：执行器不再作为 `dsh-web` 的 detached 子进程启动，改为通过 Windows Task Scheduler 一次性任务以 SYSTEM 身份独立拉起。
  - 执行器进程脱离 dsh-web 服务进程树；
  - `sc stop dsh-web` 后执行器继续存活；
  - 保留服务环境变量（`HOME / USERPROFILE / APPDATA / LOCALAPPDATA` 等），避免 pnpm 安装阶段找不到配置；
  - 执行器启动后自动清理计划任务与临时 `.cmd` 文件；
  - `EXECUTOR_VERSION` 升至 `0.1.4`，强制旧执行器版本对齐重建。

## 验证

- 单测 **59/59** 通过
- 语法检查全部通过
- `npm run build` 通过
- Task Scheduler 启动执行器实测通过：`ping` 返回 `version=0.1.4`，任务与临时文件自动清理
