# v3.2.0 — 一键重启独立功能 + 桌面快捷方式图标根治

## 变更

### 新增
- **🔁 一键重启作为独立功能正式发布**：DSH 服务异常、网页打不开时依然能一键恢复——不依赖浏览器、不依赖 3080 端口。
  - **桌面快捷方式**：插件设置「端口重启」确认态点击「桌面」→ 创建带鲸鱼图标的「重启DSH」快捷方式，双击即在命令行窗口重启并实时显示进度。
  - **命令行直接调用**：`node updater-host.cjs --cli restart --service dsh-web --profile web`——不生成快捷方式也能用，任何命令窗口可运行。
  - **跨平台**：服务化部署（Windows `sc`/nssm、Linux `systemctl`、macOS `launchctl`）+ 进程级降级重启 + 端口冲突自动 fallback 动态端口。
- **库（模块）说明**：README 新增「库（模块）说明」章节，公开 `lib/shortcut-win.cjs` / `lib/updater-host.cjs` / `lib/platform-service.cjs` / `lib/sys.cjs` 等模块的可复用 API 与使用示例。

### 修复
- **桌面快捷方式图标白纸根治**：根因是 ICO 文件损坏（`scripts/build-icon.cjs` 的 `Buffer.concat` 把 ICONDIRENTRY 与图像数据交替排列，违反 MS-ICON「entry 全在前、数据全在后」布局 → Shell 加载失败）。重建布局修正 + 图标内嵌项目（base64，16/32/48/64 BITMAPINFOHEADER）。
- **生成方案收敛为 cscript**：`update/makeShortcut` 改用 `lib/shortcut-win.cjs`（临时 VBS → cscript → WScript.Shell 创建完整 .lnk 含 IDList），Windows 自带、无 Python/pywin32 依赖；用户会话 + SYSTEM 会话实测均显示鲸鱼 ✅。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.0
```

或离线安装：

```sh
dsh plugin --profile web add ./dsh-prompt-enhancer-3.2.0.tgz
```

安装后重启 `dsh web` 生效。
