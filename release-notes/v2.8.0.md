# v2.8.0 — 一键发布模式（publish）+ 场景路由 + 方案自评

> 发布说明摘要，完整变更见 [CHANGELOG.md](../CHANGELOG.md)。

## ✨ 新功能：一键发布模式（publish）

输入一句粗略想法（如「我想开发一个纸牌游戏」）→ 一键生成**完整可实施开发规格**（九章：目标概述 / 核心玩法循环 / 数值与经济 / 数据结构与核心模型 / 核心机制与算法 / 交互与界面 / 技术实现建议 / 分阶段实施路线 / 交付验收清单）。

- **网络检索**：依据草稿主题词 + 记忆链改动方向（delta）检索同类项目结构参考，注入【网络参考】段（独立降级不阻断）
- **场景自动路由**：词表分级加权自动判定 `game/software/generic`；会话级缓存固定（首轮判定、后续轮不翻转）；软件场景第三/五章自动切换为性能指标与业务规则
- **方案自评判定**：九章输出后追加【方案自评】块——一致性/完整性/可实施性三项核对 + 【保留】/【调整】判定 + 锚点规则防自嗨；【调整】时给出 ≤5 条修订要点供下一轮补充
- **不设输出限制**：超时自动 ≥240s、输出 Token/字符上限放开（provider 默认）；设置界面三项置灰并说明
- **多轮闭环**：配合记忆链每轮输出完整九章，补充内容融入对应章节、不推翻已确认设计
