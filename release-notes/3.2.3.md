# v3.2.3 — 稳定性大修 + 一键服务化接管

> 自 v3.2.0 以来的累计更新：端口重启链路全面根治、一键更新不再卡死、支持一键安装为 Windows 系统服务。

## ✨ 新功能

- **一键服务化**：未安装系统服务时，页面直接引导一键安装（弹一次 UAC），重启电脑后自动接管端口，支持开机自启
- **崩溃自动拉起**：无系统服务时，DSH 意外退出会自动重启，不再需要手动处理
- **桌面快捷方式**：一键生成「重启 DSH」快捷方式，双击即重启（自动区分服务 / 前台模式）
- **环境检测面板**：一键检查重启工具、网络、端口托管模式与当前 PID，服务 / 前台模式一目了然
- **更新体验提升**：下载显示实时进度，失败自动切换镜像源；安装改为本地解包，不再长时间卡死

## 🐛 修复

- 端口重启：服务模式下挂死、界面卡「正在重启」、倒计时卡顿，均已根治
- 一键更新：90 秒超时、安装不生效、更新后按钮无法点击、版本检测不准
- 重启电脑后首次端口重启误报失败
- 环境检测在服务模式下误报「未安装 nssm」

## ⚙️ 变更

- 端口重启自动判断模式：已装系统服务走服务重启，否则前台重启
- 安装服务后改为「重启电脑接管」，不再引导注销
- 环境检测术语规范化：服务模式（nssm · Session 0）/ 前台模式（用户会话）

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.3
```

安装后重启 `dsh web` 生效。
