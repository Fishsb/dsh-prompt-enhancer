# v3.2.3 — 环境检测去重收敛 + 端口重启链路收官

## 变更

### 修复
- **环境检测误报「安装 nssm」（v3.2.1-w）**：nssm 已装且服务模式生效时仍提示「检测到 DSH 未以系统服务运行（无 nssm）。是否现在安装？」——根因是 v3.2.1-v 删除 host `service` 探测项后，client 三处 `svcNeedInstall` 判定仍查已删除的键（永远 undefined → 永远判需安装）。修复：判定改用 `port-mode` 四态，仅前台模式 / 未运行提示安装，服务模式 / 已装未运行 / 未知态不再误报。
- **端口重启服务模式根治（v3.2.1-u）**：`schtasks /tr` 261 字符上限导致任务链创建失败 → 只停不启 → 服务挂死。改为独立 node 脚本 + SCM 轮询 + 端口释放轮询 + 重试启动，端到端回归 5/5 通过。
- **端口重启 UI 卡「正在重启」（v3.2.1-u2/u3/u4）**：服务优雅停止时 fetch 收 FIN 误判；doneFlag 声明作用域错位（字符串注入未用唯一锚点）；倒计时递归挂在 fetch 链上变 5s 一跳——三连修复，倒计时恢复 1 秒刷新。

### 变更
- **环境检测去重收敛 + 端口托管四态状态机（v3.2.1-v）**：删除冗余 `service`/`svc-type`/`svc-bin` 三项，收敛为 4 项（tools/net/port-mode/port-pid）；`port-mode` 四态：服务模式（nssm · Session 0）/ 服务模式 · 已安装未运行 / 前台模式（用户会话）/ 未运行（无端口监听），术语文案中英同步。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.3
```

安装后重启 `dsh web` 生效。
