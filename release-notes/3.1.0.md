# v3.1.0 — 设置界面升级 + 更新按钮拆分（小版本）

> 发布日期：2026-08-16 · 自 v3.0.0 起的迭代整合：设置界面全面对齐官方 Harness 设计平台、更新流程拆分为「一键更新 + 端口重启」两步、进度反馈细粒化。

## ✨ 更新按钮拆分（用户需求）

- **「一键更新」**：合并原「一键拉取更新」与「一键更新」——执行器新增 `restart:false` 模式：下载 → 校验 → 停服 → 安装，**不重启**（服务保持停止）
- **「端口重启」**：独立重启按钮（仅重启循环，5 轮 stop+start + 端口健康检查）
- 两按钮同置于「目标目录」行末，均带确认态与互斥禁用；安装完成显示「✓ 已安装，请点击端口重启生效」引导
- 执行器版本 0.1.6 → 0.1.7（executorEnsure 自动版本对齐）

## 🎨 设置界面对齐官方 Harness

- **样式**：控件字号 12→13px、圆角/边框/背景层全面对齐官方 design platform（token 化，明暗双主题自适应）
- **交互**：tab 键盘导航（方向键/Home/End + roving tabindex）、卡片 hover 反馈、主按钮官方实底范式
- **可访问性**：label htmlFor/id、hint aria-describedby、折叠区 aria-controls、设置页标题+简介
- **间距修复**：优化参数板块行间 12px、提示贴控件 4px；模型链行间 10px

## 🚀 优化体验

- **细粒度进度反馈（v3.0r）**：标准/专家/一键发布检索期间按钮进度全程动态（子步骤 + 已用秒数，如「正在搜索 2/3：体素引擎 · 8s」），消除卡顿误判
- **记忆链发送清空（v3.0s）**：发送消息即清空记忆链——持续记忆仅限发送前一轮优化内的会话
- **智能模式更名**：「智能」→「专家」（英文 Smart→Expert；内部值不变，存量配置零迁移）

## 🔧 工程

- `bundle-smoke` 测试（SMK-01..17）纳入 `npm test`——112/112 全量通过（此前仅 95）
- 清理 constants.js 遗留死代码、历史快照与旧发布说明

## 📦 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.0
```

安装后重启 DSH（`dsh web`）。或从 [Releases 页面](https://github.com/Fishsb/dsh-prompt-enhancer/releases) 下载 `dsh-prompt-enhancer-3.1.0.tgz` 本地安装。
