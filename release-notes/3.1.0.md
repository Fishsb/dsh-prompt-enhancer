# v3.1.0 — 模板体系扩展 + 下拉框动效升级 + 配置卫生专项

> 发布日期：2026-08-17 · 自 v3.0.0 以来的迭代统一归档：模板体系全面扩展（每模式 3 内置 + 多自定义）、设置页下拉框动效与可读性升级、模型配置残留与错位专项修复。

## ✨ 模板体系扩展（每模式 3 内置模板 + 多自定义模板）

设置页「模板」由「内置/自定义」全局开关升级为**每模式模板选择**：

- 每个优化模式（基础/轻量/标准/专家/一键发布）各有 **3 个内置模板**：
  - **模板1 默认模板**——现有提示词，行为零变化
  - **模板2 增量补充完善**——在原有内容基础上补充与完善
  - **模板3 增量完善（开发向）**——面向开发人员，开发化表达、技术术语与代码相关名词；一键发布模式独立适配九章规格
- **自定义模板可添加多个**（每模式 ≤10 个，各 ≤4000 字符，可命名/编辑/删除），新建时以当前选中模板内容预填
- 旧「内置/自定义」配置**自动迁移**（行为等价，不丢内容）；非法/越界选中自动回退默认模板

## 🎨 下拉框动效与可读性升级（设置页）

- **所有下拉框箭头位占位**：右侧预留 28px 箭头位，避免文字与末尾向下箭头重叠；固定宽度窄下拉同步加宽
- **选中文本超宽自动循环滚动**：选中项超出显示宽度时在可见区域内左右循环滚动展示完整内容（未溢出保持省略号静止），无需手动操作
- **打开态悬停选项自动滚动**：下拉打开后，鼠标悬停到超宽选项上即自动滚动展示完整内容
- 修复两处回归：行溢出不再把顺序调整/删除/测试按钮推出面板（`box-sizing` 修正）；下拉字体颜色恢复正常
- 修复滚动条不可交互：原生 `<select>` 改 `pointer-events:none`，文本区/箭头可交互，滚动条可拖动

## 🐛 配置卫生专项：模型配置残留与错位修复

- **失效条目可见化**：模型链条目指向不可用 provider/模型时显示 ⚠ 标记 + 顶部提示 + 一键清理
- **思考等级自动纠偏**：已启用思考的条目 resolve 时校验存储等级，不在模型能力列表 → 按默认等级修正；模型不支持思考 → 自动移除（不再把失效 effort 随请求发给 LLM）
- **切换厂家/模型不再静默重置思考等级**（保留字段，能力纠偏接管）
- **自定义模板清空可持久**：编辑过的模式不再被自动回填（新增 `touched` 标记），未编辑模式保留首访预填
- **sanitize 版本门控**：未来结构配置不 sanitize、不写回，以默认配置运行并提示（保护用户数据）
- **M3 脚手架语义对齐**：`config-schema.validateConfig` 补齐白名单，新增 U-parity 奇偶单测锁定语义一致
- **删除/移动行不再错标**：测试结果区按条目身份（provider/model）而非 index 定位
- **残留清理**：order 幽灵键打开设置页自动清理、遗留 template.text 写回即清除、关闭思考不再写入冗余字段
- 「恢复默认」走 noCache 最新自适应链，README/设置页明确其语义（仅重置模型链）

## 🔄 更新与文档

- **端口重启默认可用**：不再依赖「检测到新版本」前置，始终可点（纯重启服务本就不需新版本）
