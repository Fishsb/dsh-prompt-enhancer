# v3.1.1 — 一键更新不重启修复 + 重启进度反馈（补丁版）

> 发布日期：2026-08-16 · 自 v3.1.0 起的修复迭代：修复「一键更新」误触发服务重启，并优化重启过程的进度反馈。

## 🐛 修复：一键更新不再自动重启服务

- **根因**：运行中的更新执行器仍是旧版（0.1.6，无 `restart:false` 支持），旧 dsh-web 进程内的版本号被缓存、执行器永不升级，旧执行器忽略「只安装不重启」参数、自动拉起服务
- **修复**：① 一键更新前校验执行器版本，过旧则阻止并提示重启 dsh-web 升级；② 执行器版本目标改从磁盘解析，旧服务也能自动升级执行器
- 现在「一键更新」= 下载 → 校验 → 停服 → 安装，**不重启**；装完显示「✓ 已安装，请点击端口重启生效」，由「端口重启」按钮拉起

## ⚡ 重启进度反馈优化

- 「端口重启」不再长时间无反馈：**每秒**更新倒计时（原每 2 秒一次）
- 状态行实时展示执行器阶段：正在停止服务 / 服务已停止，等待稳定 / 第 N 次重启：停止+启动 / 端口未就绪，准备重试 + 轮次 + 剩余秒 + **已用秒数**
- 执行器长时间无响应（约 15 秒）自动终止并提示，不再无限等待

## 📦 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.1
```

安装后重启 DSH（`dsh web`）。或从 [Releases 页面](https://github.com/Fishsb/dsh-prompt-enhancer/releases) 下载 `dsh-prompt-enhancer-3.1.1.tgz` 本地安装。
