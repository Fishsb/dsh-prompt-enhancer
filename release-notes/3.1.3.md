# v3.1.3 — 检索参考真正可用 + 记忆链继续优化提速

## 变更

### 修复
- **修复「恢复默认模型链」失效**：`models/autochain` RPC handler 签名漏 `args`，导致恢复默认只能回退静态链。

### 优化
- **参考上下文从「仅供背景」改为「吸收明确需求」**：检索/记忆参考中的明确需求、约束、默认值会被吸收进优化结果，禁止逐字复述；参考真正有用，不再只是背景噪音。
- **记忆链「继续优化」改为基于本轮改动直接优化**：不再重复走完整检索流程，跳过会话/文档/网络检索，以【本轮修改】为主要方向，输出完整更新后的提示词；继续优化更快、更聚焦。
- **模型响应看门狗超时 3s → 5s**：降低模型慢启动被误杀的概率。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.3
```

或离线安装：

```sh
dsh plugin --profile web add ./dsh-prompt-enhancer-3.1.3.tgz
```

安装后重启 `dsh web` 生效。
