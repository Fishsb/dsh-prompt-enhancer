# 🧠 发送前多轮迭代：记忆链 + 继续优化（v2.7.0）

## 记忆升级：多轮迭代链（记忆开关开启时）
- **之前**：只记住上一轮优化结果，再优化时只参考一对「输入/输出」
- **现在**：发送前「优化 → 修改 → 再优化」的每一轮改动都会累积（最多最近 4 轮输入/输出），再优化时以**真多轮 user/assistant 对话消息**代入全部轮次，让模型理解你的意图演化
- **修改方向感知**：通过行级 diff 自动识别你相对上一轮结果的调整（`+新增 / -删除` 摘要 ≤300 字符），明确告诉模型"这轮你改了什么"
- **预算规则**：记忆链 ≤2400 字符按轮等分（输入 1/3、输出 2/3），与上下文预算联动；记忆注入同样触发防回显护栏
- **撤回语义**：撤回只弹出最后一轮（更早轮次仍有效）；关闭开关后完全不读取/写入

## 按钮「继续优化」状态
- 首次优化完成后，继续修改草稿 → 按钮变为**纯文字「继续优化」**（无 ✨ 图标，hover 提示同步区分）
- 撤回 = 回到起点，按钮恢复首次形态（✨ + 模式短标签）
- 优化中（spinner + 进度）、完成（撤回）、空输入（记忆开关）、守卫禁用等其余状态不变

## 说明
- 记忆链仅存于当前页面内存（不落盘），随优化请求发送给所选模型厂商；关闭开关即停止读取/写入
- 单测 50/50 通过；host 纯函数族（buildChatMessages / computeEditDelta / buildMemoryDeltaHint）全部可单测
