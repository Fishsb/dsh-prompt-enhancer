# v3.1.4 — 连通性测试结果区重做：双模式预计耗时 + 测量修正

## 变更

### 新增
- **连通性测试展示「基础模式」与「轻量模式」两个预计耗时**：测试成功后，实测/历史分别标注 `基础模式预计约 X` 与 `轻量模式预计约 Y`，按当前输入长度动态估算。轻量模式按实际功能建模——它含「检索引入会话」（读取最近 1 轮会话 + LLM 关联判定调用），预计耗时比基础模式更长。

### 修复
- **TTFT 显示单位修复**：此前「首 token」误把毫秒当秒格式化（TTFT 4705ms 显示成 `78m25s` 的离谱数据），现 <1s 显示 `78ms`、≥1s 显示 `4.7s`。
- **tps 测量失真修复**：探测从「short 200-token」改为「长文 ~1200-token」——此前模型只吐几个 token、decode 窗口仅 ~2ms，tps 被数学放大到虚高的 4500 tok/s（真实量级 75–267 tok/s）；长文探测让 tps 落回真实区间。探测保持「未开思考」口径（TTFT 不含思考时间），`models/test` 超时放宽到 30s。

### 优化
- **测试结果区布局调整**：✓ 可用/✗ 失败状态与「测试 #N · 厂商 / 模型」同行显示，实测/历史各占一行，字号与标题对齐。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.4
```

或离线安装：

```sh
dsh plugin --profile web add ./dsh-prompt-enhancer-3.1.4.tgz
```

安装后重启 `dsh web` 生效。
