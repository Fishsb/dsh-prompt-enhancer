# v3.5.1 — 改名后的收尾修复版

> v3.5.0 把项目整体改名到 `dsh-voice-prompt-enhancer`（原 npm 包名已被他人占用）。本版修掉改名留下的最后两处不一致，并把发布渠道理顺：npm 首次可直装。

## 🐛 修复

- **执行器目录仍拼旧包名**：`EXECUTOR_ROOT` 之前写死 `dsh-prompt-enhancer`。改名后新装用户会落到新目录、老用户仍在旧目录，两边各跑一份。现在改为**新名优先、旧名回退**：老用户继续用旧目录，不用重装；新装用户写入新名目录。

## 📦 安装

npm 已可直装（推荐）：

```sh
dsh plugin --profile web add dsh-voice-prompt-enhancer@3.5.1
```

GitHub 源安装仍然可用：

```sh
dsh plugin --profile web add github:Fishsb/dsh-voice-prompt-enhancer#v3.5.1
```

## 🔁 从 3.5.0 升级

直接覆盖安装即可。**配置文件会自动迁移**：首次读取时把旧的 `dsh-prompt-enhancer.*` 复制成新名文件，旧文件保留为 `.migrated` 备份。你的模型链、语音开关、增强模式都会带过来。

旧包名还会作为读取候选保留到下一版；再下一个版本才会整体退役。所以这一版**不需要你做任何手工迁移**。
