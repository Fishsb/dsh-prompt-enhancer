# v3.3.2 — 稳定性大修 + 语音体验升级 + 治理加固

> 43 项迭代攒批：提示词增强管线服务化、语音识别本地引擎与多步检索、端口重启加固、配置磁盘持久化，以及「优化完成但草稿未替换」等关键修复。

## ✨ 新增

- **语音识别模块**：云端双协议（Qwen3-ASR chat / OpenAI）+ 本地引擎（sherpa-onnx 离线）；模型市场内置 sense-voice/paraformer 一键下载，多源 fallback 与显式下载代理；识别结果可选 LLM 规整（失败降级原文）
- **一键发布模式（publish）**：粗想法 → IEEE/GDD 九章需求规格，多步网络检索 + 跨轮记忆回注
- **会话切换增强保持**：优化中切走后台继续、回归自动恢复现场、localStorage 结果持久化
- **单快捷方式三功能**：Start Web / Repair port / One-click update 全自动；维护菜单同步瘦身
- **nssm 异常自愈阶梯**：软重启→强停借力→末次重试→卸载兜底（带确认门），并发闸防双实例
- **救援五步流程**：依赖冲突诊断 → 快照 → 三档处置 → 干跑闸门 → 验证拉起，附恢复报告
- **供应链加固**：staging tgz sha256 强校验；web/desktop 双实例隔离
