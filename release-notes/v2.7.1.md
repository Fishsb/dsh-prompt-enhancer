# 🔧 v2.7.1 · 继续优化修正 + 已保存判定优化（patch）

> v2.7.0 基础上 +0.0.1（patch），合并本迭代全部未发布改动。

## 继续优化遗留修正
- **发送 / 清空输入框 → 恢复初始形态**：点击发送（composer 清空）或手动清空输入框后，按钮恢复「优化」初始形态（不再残留「继续优化」状态）
- **后台记忆不清除**：发送/清空均保留记忆链（持续记忆）——用户删除内容可能表示方向调整或反馈方向不正确；仅撤回（undo）弹出最后一轮

## 记忆机制明确
- 记忆链 = **固定窗口最近 4 轮** `{input, output}`（FIFO 滚动；注入按 ≤2400 字符预算等分截断，输入 1/3、输出 2/3）
- 发送/清空不清除（持续记忆）；撤回只弹最后一轮；关闭开关后完全不读取/写入
- 仅存当前页面内存（不落盘），按会话隔离

## 设置「已保存」判定优化
- 改动后 **1s**（防抖，连续改动只校验最后一次）执行**真实检查**（localStorage 读回逐字对比）
- 检查伴随**转圈动效（保底 0.5s）**；已落实 → 「✓ 已保存」（3s 后消失）/ 未落实 → 「✗ 保存失败，请重试」
- 无 timer 服务降级为旧常驻提示

## 说明
- 单测 50/50；保存时序模拟验证（1s + 0.5s 保底 = 1516ms）；清空复位模拟验证
- 升级方式：`dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v2.7.1` + 重启 GUI（重启后 executorEnsure 自动对齐执行器 0.1.2）
