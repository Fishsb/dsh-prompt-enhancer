# v2.8.3 — 一键更新 install timed out 修复

> 发布说明摘要，完整变更见 [CHANGELOG.md](../CHANGELOG.md)。

## 修复内容

- **一键更新 install timed out / 操作失败**：
  - 根因：Windows 下 `dsh-web` 服务运行时会占用 `node_modules/dsh-prompt-enhancer` 目录文件，导致 pnpm 替换插件目录时出现 `EPERM` 或长时间卡住，最终被 120s 超时中断。
  - 修复：`apply` 流程改为“先停止服务 → 执行安装 → 安装成功后再启动服务并健康检查”。
  - 安全兜底：安装失败会自动尝试恢复启动服务，避免服务一直处于停止状态。
  - `EXECUTOR_VERSION`：`0.1.4 → 0.1.5`，强制旧执行器重建。

- 语法检查通过
- `npm run build` 通过
