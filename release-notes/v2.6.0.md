# ⚡ 更新执行器独立化（v2.6.0）

## 架构
- **独立更新执行器**（`lib/updater-host.cjs`，常驻进程 127.0.0.1:3081）：安装 + 重启全程脱离 dsh-web——服务停止/崩溃期间它存活，独立完成「stop → 3s 缓冲 → start → 端口健康检查 → 最多 5 次自动重试」
- host 只负责 `update/executorEnsure`（拉起/版本对齐）；client 经执行器 apply 后轮询 status（倒计时 + 每轮反馈，服务重启不断连）

## 修复（v2.5.x 顽疾根因）
- **`timeout` 缓冲从未生效**：非交互环境（stdio ignore）下 `timeout` 立即返回（实测 169ms）→ net stop 后立即 net start 的竞态崩溃——执行器改用 node `setTimeout`（3s 缓冲）可靠等待
- **依赖 host 的重试必然失效**：服务停 = host 死 = 重试 RPC 无人接收——重试移入独立执行器（5 次健康检查循环）

## 验证
- 前置实验：detached 进程在服务重启中存活 ✓
- 测试端口链路走通：restart 一次 healthy ✓；白名单拒绝非法 tag/repo ✓
- 单测 47/47

## 使用
- 无需额外配置；默认端口 3081（`updater.executorPort` 可改）；一键更新流程不变（点按钮 → 自动完成）
