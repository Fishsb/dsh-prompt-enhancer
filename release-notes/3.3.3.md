# v3.3.3 — 增强易断链修复 + 更新链治理加固 + 外部贡献处理

> 10 项迭代攒批：增强链路看门狗/探测窗口放大与链级重试、更新器自动链熔断与重启防抖、部署账本与自愈版本守卫、probeEnv 全异步化、日志全链 ISO 时间戳，以及外部 fork/PR 贡献评估与 README 采纳。

## 🐛 修复

- **增强易断链修复**：看门狗 5s→15s、探测 3s→12s、失败缓存 30s→5s；链耗尽整链重试一次（最多 2 pass，重试轮免看门狗）——「慢但健康」模型不再被误杀，瞬时限流/慢首字/网络抖动自愈
- **恢复被批次D误删的 require 绑定**：`asrDeploy`/`sys` 锚点原位恢复 + LIBWIRE 锚点测试防复发
- **package.json 描述 emoji 乱码修复**：第三方市场分发面元数据恢复（UTF-8→GBK 编码事故）

## 🛡️ 稳定性与治理加固

- **部署账本 + 自愈版本守卫**：`dsh-prompt-enhancer.deploy.json` 四入口原子记账；heal 前置基线守卫（陈旧缓存拒绝恢复）；维护菜单新增「一致性自检」五项
- **更新器自动链熔断**：显式代理下载（失败降级直连）+ 失败指数退避（60s×2ⁿ 封顶 30min，每日上限 6 次）+ kill-switch 总开关 + 重启调度双闸防抖（5min 窗口）+ exec-* 计划任务残留三连修
- **probeEnv 全异步化**：事件循环阻塞 775–836ms 降至毫秒级心跳抖动；net 探测熔断冷却（3 连败 10min 冷却窗，旋钮可关）
- **日志全链 ISO 时间戳**：hlog/herr 统一 `[YYYY-MM-DDTHH:mm:ss.sssZ]` 前缀（77 处零编辑覆盖）；bundle 外 console 直写收编 logT 包装（15 处 + stage-install 4 处）
- **发布物 BOM 收口声明**：仓库源与安装链 sha256 强校验闭环（上游 dsh-app-boot BOM 容忍问题维持跟踪、不代修）
