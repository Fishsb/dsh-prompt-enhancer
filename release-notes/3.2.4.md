# v3.2.4 — 修复桌面端配置丢失

> 修复 DSH 桌面版（Desktop）每次重启后插件设置被重置的问题（GitHub Issue #1）。

## 🐛 修复

- **桌面端设置不再丢失**：修复 DSH Desktop 每次重启后模型链、优化参数、自定义模板被重置为默认值的问题
- **配置磁盘持久化**：配置改为跨端口共享的磁盘存储，桌面端动态端口切换后自动恢复，无需重新配置
- **网页版零影响**：固定端口（网页版）原有配置自动迁移到磁盘，行为不变

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.4
```

安装后重启 `dsh web` 生效。
