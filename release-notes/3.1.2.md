# v3.1.2 — 更新/重启职责划分 + 端口重启误报修复（补丁版）

> 发布日期：2026-08-16 · 自 v3.1.1 起的修复与职责划分：一键更新仅下载，端口操作统一归端口重启模块。

## 🔀 一键更新与端口重启职责划分（用户需求）

- **「一键更新」仅执行更新操作**：下载 + 校验新版本资源到本地 staging——**不停止服务、不安装、不触碰任何端口**，执行期间 GUI 全程可用
- **「端口重启」统一承载所有端口操作**：停止服务 → 安装已下载的新版本 → 启动 + 健康检查（重启失败自动回滚旧版本）；也可单独重启服务（未先更新时）
- 新流程：检测版本 → **一键更新**（下载，无感）→ **端口重启**（安装+重启，秒级进度反馈）

## 🐛 修复：更新完成后端口重启误报「执行器不可用」

- 旧版「一键更新」安装后服务停止，此时「端口重启」依赖的服务端 RPC 不可达 → 误报「请确认插件为 bundle 安装（端口 3081）」
- 修复：端口重启**直连独立执行器**（3081，不受服务启停影响），仅在执行器真正不可达时才显示该提示

## 📦 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.2
```

安装后重启 DSH（`dsh web`）。或从 [Releases 页面](https://github.com/Fishsb/dsh-prompt-enhancer/releases) 下载 `dsh-prompt-enhancer-3.1.2.tgz` 本地安装。
