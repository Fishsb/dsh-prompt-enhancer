# v3.1.2 — 修复一键更新后端口重启按钮无法点击

> 发布日期：2026-08-17 · 修复 v3.0.0「一键更新与端口重启职责划分」引入的交互回归：一键更新（仅下载新版本到 staging）完成后，端口重启按钮看似可点却无响应。

## 🐛 修复内容

- **一键更新后端口重启点不了**：一键更新（staged 模式）完成后状态为 `staged`（新版本已下载、服务未重启），此时端口重启按钮未置灰、但点击进入确认态的逻辑白名单只放行 `idle/installed`，`staged` 被静默忽略——现已放行 `staged` 态下的端口重启，点击可正常进入确认态完成「安装 + 重启」
- 未点一键更新（`idle` 态）端口重启一直正常，不受影响

## 📦 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.1.2
```
