## ⚡ 一键更新并重启

- 检测到新版本后，卡片提供「⚡ 一键更新并重启」按钮：二次确认 → host 自动执行官方安装命令 → **安装成功才自动重启服务**（失败绝不重启）→ 页面提供刷新按钮，刷新即新版本生效
- 全程无需复制命令到命令行；支持 `updater.serviceName`（默认 `dsh-web`）/ `updater.profile`（默认 `web`）配置

## 🧪 环境检测

- 卡片行 1 新增「环境检测」按钮（样式同「检查版本」）：只读探测 7 项——网络连通性 / 服务名存在 / 服务账号权限 / 服务可重启 / 端口占用 / 安装形态 / pnpm 注入机制，每项 ✓/⚠/✗ 附指引
- 一键更新前自动前置校验：环境不满足（如服务名错误、账号非 LocalSystem）会阻止并列出缺失项
