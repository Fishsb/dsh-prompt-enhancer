# v3.4.0 — 兼容性修复版（✨ 按钮恢复 + 云端语音修复）

> 本版主线是**两处让功能整体不可用的问题**：DSH 宿主升级后 ✨ 增强按钮不再渲染、云端语音识别恒失败。两者都已在市场版本（v3.3.3）上复现并被用户报告（Issue #8 / #10 / #9）。
> ⚠️ 同时含一处**破坏性变更**（移除插件内重启能力），详见文末「升级注意」。

## 🐛 修复

- **✨ 增强按钮 / EnhanceBar 在 DSH Desktop 与运行时 1.0.61+ 上不渲染**（Issue #8 / #10）：宿主槽位渲染器已改为 hook 契约——向槽位组件注入 `useSession` / `useInput` 选择器 hook 与 `inputActions`，**不再传 `props.session`**；插件仍按旧取法取值，组件直接返回 null，表现为「设置页里插件正常、输入框上的 ✨ 却消失」。本版按新契约取值，并**向下兼容旧宿主**（仍提供 `props.session` / `props.input` 的运行时照常工作）。
- **云端语音识别恒失败**（Issue #9）：chat 协议请求体里音频字段名写成了 `audio`，应为 `input_audio`，服务端一律拒绝。修复后云端 ASR 恢复；本版同时补上了针对该出网契约的自动化断言，防止同类字段名笔误再次静默上线。

## 🛡️ 稳定性与平台修复

- **非 Windows 平台三处真缺陷**：① 环境探测的工具白名单缺 `which`，导致非 Windows 侧整套探测走「工具不可达」早退；② 端口监听者探测依赖的 `lsof` 既不在常见镜像里、其输出格式又与解析正则不匹配，导致永远拿不到 pid；③ 错误日志尾部读取被一处平台判断整条短路，连平台无关的降级日志也读不到。三处均已修（Windows 行为不变）。
- **一键更新的拉取清单与发布树对齐**：清单里残留一个已下线的文件，而校验要求「恰好覆盖清单全项」——意味着该路径此前不可能成功。
- 内部：CI 从「长时间不出结论」改为**每次推送给出完整读数**，并新增「用例注册数 ≥ runner 上报数」不变量（防「用例静默消失但 CI 报绿」）；死层清理使发布物体积下降约 27%。

## ⚠️ 升级注意（BREAKING）

- **移除插件内的重启能力**：一键更新完成后不再由插件自动重启 DSH，改为提示你**手动重启**；原先的「重启服务/端口」按钮与「桌面快捷方式」入口一并下线。
- 对外 RPC 变更：`update/portRestart`、`update/makeShortcut` 不再提供；新增 `update/install`（安装已下载的新版本，返回 `restartNeeded: true`）。
- 若你此前依赖快捷方式或插件内重启，请在更新后改为手动重启 DSH（`dsh web`）。其余功能与配置**无需迁移**。

dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.4.0
