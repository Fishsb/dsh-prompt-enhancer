# v3.2.1 — 端口重启全链路加固 + 快捷方式权限 + 模块解耦

> 说明：本版本经历了大量实测驱动的迭代（v3.2.1-g~o），部分中间方案（如 schtasks 一次性时间点任务）已被后续版本取代，最终形态见下。

## 变更

### 修复
- **端口重启服务模式加固**：判断规则改为「有 nssm 服务即服务模式（RUNNING→sc stop→sc start；Stopped→显式拉起），默认前台仅兜底」——设置内端口重启与桌面快捷方式口径一致（v3.2.1-j）。
- **schtasks 触发修复**：一次性时间点任务实测错过触发（267011）→ 改为创建后立即 `/run` 触发（v3.2.1-j）。
- **默认模式杀实际监听者**：taskkill 目标改为 3080 实际监听者（netstat 查，索引仅兜底）——根治「索引死→taskkill 无效→EADDRINUSE 崩溃→索引再污染」恶性循环；poll 成功条件改为新 PID 接管防误报（v3.2.1-l）。
- **快捷方式权限**：创建时给 .lnk 打 RunAs 标志 + 脚本全模式权限拦截（非管理员明确提示失败，v3.2.1-k/m）。
- **UI 回滚**：版本检测与更新卡片放回插件管理 tab（功能/逻辑解耦保留，独立 updaterCfgState 配置）——用户确认解耦要的是功能分离而非 UI 分离（v3.2.1-j）。
- **一键更新下载镜像 fallback**：github 直连失败自动切 ghproxy 类镜像（v3.2.1-p）。
- **安装文案**：去掉「或注销」（实测注销不触发 Auto 服务启动）。

### 变更
- **环境检测项重构**：`exec-port`（更新端口独立，默认端口解析必失败）删除 → 新增「端口托管模式（nssm 服务会话0/前台默认/无监听）+ 当前端口 PID」（v3.2.1-o）。
- **模块解耦**：服务端口（update/*）与提示词增强（enhance/models/template）功能独立，配置完全分离（v3.2.1-i）。

### 清理
- 删除死代码 buildLnk、probePortOccupied 等（v3.2.1-n）。

## 安装

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.1
```

> ⚠️ 建议直接安装 v3.2.2（含一键更新链路根因修复：安装与 host 解耦、版本检测运行时读取）。
