# dsh-prompt-enhancer

A prompt-enhancement plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH): type a rough prompt in the composer, click ✨, and an independent LLM call rewrites it in place — fully undoable.

## ✨ Highlights

- **One-click enhance** — the ✨ button triggers an independent LLM call and replaces the draft in place; continue refining, undo anytime, or cancel while enhancing
- **5 optimization modes** — Basic (direct) / Lite (previous-round context) / Standard (rules + retrieval) / Expert (task analysis + full retrieval) / One-click Publish (complete dev-spec generator)
- **Memory switch** — when on, pre-send rounds (optimize → edit → re-optimize) accumulate into a memory chain the next round replays and senses your edit direction; sending the message clears it; when off, nothing is read or written
- **Model chain** — try multiple models in order, reorder, toggle thinking, run inline connectivity tests
- **🔁 One-click restart (standalone feature)** — restart DSH even when the web UI is down: double-click the desktop shortcut (whale icon) or invoke the CLI directly; supports service-managed (Windows/Linux/macOS) and process-level fallback restart
- **i18n** — follows the DSH interface language (中文 / English)

## 🚀 Install

```sh
dsh plugin --profile web add github:Fishsb/dsh-prompt-enhancer#v3.2.0
```

Restart DSH (`dsh web`) after installing — the ✨ button appears in the composer toolbar.

> Requires [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) installed locally and `pnpm` in PATH.

Update / remove:

```sh
dsh plugin --profile web update dsh-prompt-enhancer
dsh plugin --profile web remove dsh-prompt-enhancer
```

> After `remove`, restart DSH to fully unload the running instance.

## 🔁 One-click restart (standalone feature)

> Goal: **restart DSH even when the service is broken and the web UI is unreachable** — no browser, no 3080 port required.

### Way 1: Desktop shortcut (recommended)

After installing, open the plugin settings → "Restart port" confirmation and click "**Desktop**" — a whale-icon "Restart DSH" shortcut is created. Double-click it to restart DSH in a CLI window with live progress:

```
=== DSH port restart (CLI) ===
  service: dsh-web  executor port: 3081
[3s] stopping round 1 — Stopping service…
[12s] restart round 2 — Port not ready, retrying
[18s] ✅ Service restarted (healthy)
```

### Way 2: Direct CLI invocation

**No shortcut needed** — the core is the executor's CLI mode; run it from any command window (cmd / PowerShell / Git Bash):

```sh
node "<DSH_HOME>\AppData\Local\dsh-prompt-enhancer\executor\0.1.11\lib\updater-host.cjs" --cli restart --service dsh-web --profile web
```

Arguments (all optional):

| Argument | Default | Purpose |
|---|---|---|
| `--service` | `dsh-web` | Service name |
| `--profile` | `web` | DSH profile |
| `--executor-port` | `3081` | Restart executor port |

Flow: it first calls the **running restart executor** (SYSTEM privileges, can control the service) and polls progress; if the executor is not running, this process restarts the service directly (if it reports no permission, open the window as Administrator).

### Restart capability

- **Service-managed**: Windows (`sc`/nssm), Linux (`systemctl`), macOS (`launchctl`) — unified by `lib/platform-service.cjs`
- **Process-level fallback**: when not service-managed, read the DSH process index → kill the old process → spawn a new one with the same args → probe the port (inspired by the dsh-restart ecosystem)
- **Port-conflict adaptive**: if the executor port is taken, it falls back to a dynamic port (`executor.port`); restart keeps working

## 📦 Library (module) notes

Core logic is split into standalone Node modules, reusable from other tools/scripts:

| Module | Responsibility | Reusable capabilities |
|---|---|---|
| `lib/shortcut-win.cjs` | Windows desktop shortcut generation | `makeShortcutWin()` — writes a temp VBS → cscript creates a full .lnk (with IDList + whale icon) → returns path/size; `fixTargetUnicode()` patches the icon field |
| `lib/shortcut-icon.cjs` | Whale icon for shortcuts | `shortcutIconBuffer()` — embedded base64 ICO (16/32/48/64, BITMAPINFOHEADER), generated by `scripts/build-icon.cjs` |
| `lib/updater-host.cjs` | Update executor + CLI restart | CLI: `node updater-host.cjs --cli restart --service <svc>`; HTTP RPC: `ping` / `restart` / `status` (port 3081) |
| `lib/platform-service.cjs` | Cross-platform service management | `detectService` / `readPort` / `stopService` / `startService` / `isStopped` / `pid` — win32 sc/nssm, linux systemctl, darwin launchctl |
| `lib/sys.cjs` | Env & paths | `EXECUTOR_ROOT` / `executorDir()` / `readExecutorPortFile()` / `probeEnv` |

**Example: generate a "Restart DSH" shortcut from another Node script**

```js
const { makeShortcutWin } = require('dsh-prompt-enhancer/lib/shortcut-win.cjs');
const os = require('node:os');
const path = require('node:path');

const iconPath = path.join(os.homedir(), 'AppData', 'Local', 'dsh-prompt-enhancer', 'executor', 'icons', 'deepseek.ico');
const result = makeShortcutWin({
  lnkPath: path.join(os.homedir(), 'Desktop', 'Restart DSH.lnk'),
  target: 'C:\\Windows\\System32\\cmd.exe',
  args: '/c "C:\\Users\\lk\\AppData\\Local\\dsh-prompt-enhancer\\executor\\cli\\restart-dsh.cmd"',
  workingDir: os.homedir(),
  iconPath,
  iconPathEnv: '%USERPROFILE%\\AppData\\Local\\dsh-prompt-enhancer\\executor\\icons\\deepseek.ico',
});
console.log(result); // { ok: true, shortcutPath, size, ... }
```

## 🎯 Usage

1. Type any non-empty text (slash commands keep their prefix; only the body is optimized)
2. Click the **✨** button
3. Wait for the independent LLM call; the draft is replaced with the enhanced version
4. Not satisfied? Click **Undo** to restore the original
